# lita-tokenizers-core

[![crates.io](https://img.shields.io/crates/v/lita-tokenizers-core.svg)](https://crates.io/crates/lita-tokenizers-core)
[![docs.rs](https://docs.rs/lita-tokenizers-core/badge.svg)](https://docs.rs/lita-tokenizers-core)
[![License](https://img.shields.io/crates/l/lita-tokenizers-core.svg)](https://crates.io/crates/lita-tokenizers-core)

It provides the core traits and configurations for tokenizers, which are used internally by [LiTA](https://www.lsta.media.kyoto-u.ac.jp/lita/).

Note that this is very the fundamental and low-level APIs: in most cases you shold prefer [`lita-tokenizers`](../lita-tokenizers) instead.
